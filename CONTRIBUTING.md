# Contributing to core-numerics

Thank you for your interest in contributing to `core-numerics`.

This repository is intended to grow into a reusable scientific computing
library for numerical methods, validation tools, and research-quality examples.

## Development Principles

Contributions should aim to be:

- Clear
- Modular
- Tested
- Documented
- Reproducible
- Numerically validated when appropriate

## Code Style

- Use clear names for variables, functions, and modules.
- Keep numerical methods separated from problem-specific examples.
- Prefer small, reusable functions over long scripts.
- Document mathematical assumptions and numerical schemes.
- Include references when implementing published algorithms.

## Testing

New code should include tests when possible.

Tests should check:

- Correctness of basic operations
- Expected convergence behavior
- Conservation properties when relevant
- Reproducibility of numerical results

## Documentation

Documentation should explain both:

- How to run the code
- What numerical method is implemented

## Research Software Goal

The long-term goal is to make this repository useful for scientific computing,
applied mathematics research, and reproducible numerical experiments.

# core-numerics

Reusable numerical methods and scientific computing utilities for research in
computational mathematics, numerical PDEs, and biofluid mechanics.

This repository will contain modular implementations of numerical methods,
validation tools, convergence studies, and examples for long-term research
software development.

## Planned Modules

- Linear algebra
- Iterative methods
- Time integrators
- Error analysis
- Convergence studies
- Validation tools
- Benchmark problems

## Goals

- Build reusable numerical methods
- Document algorithms clearly
- Include tests and validation cases
- Support reproducible computational research
- Grow toward publication-quality scientific software
